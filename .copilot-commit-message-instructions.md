# Commit Message Guidelines

## Format
Use Conventional Commits: `type(scope): short summary`

Types: feat, fix, refactor, docs, chore, test, style

## Subject line
- Under 72 characters
- Imperative mood ("add" not "added")

## Body
Always include a body with bullet points that explain:
- What changed
- Why it changed (if not obvious)

## Example
feat(ui): add home screen and add/edit task modal sheet

- HomeScreen now doubles as the task list for now
- Add/edit task form opens as a modal bottom sheet
- No CREATE/UPDATE wiring yet; _save() throws UnimplementedError
